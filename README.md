# jquery-combogrid

Based on jQuery UI Combogrid 1.6.4 by D'Alia Sara. The source website (http://combogrid.justmybit.com/) no longer exists.

## Contributing

Before committing changes:

- Test!
- Run the build script: `yarn run build`.

Before creating a new release:

- Update the changelog.  Use [Common Changelog style](https://github.com/vweevers/common-changelog).
- Update the version-number in `package.json`.
